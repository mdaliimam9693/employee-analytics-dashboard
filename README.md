# Employee Analytics Dashboard 📊

This is a Python + Pandas based Employee Analytics Dashboard project created for data analysis practice.

## 🚀 Features

- Total Employees Count
- Average Salary
- Highest Salary
- Lowest Salary
- Department-wise Employee Count
- City-wise Employee Count
- Top 5 Highest Paid Employees
- Latest Joined Employee
- Department-wise Average Salary
- Auto Generated Report.txt File

## 🛠️ Technologies Used

- Python
- Pandas

## 📂 Files Included

- employees_dashboard.py
- employees_1000.csv
- report.txt

## ▶️ How to Run

```bash
py employees_dashboard.py
